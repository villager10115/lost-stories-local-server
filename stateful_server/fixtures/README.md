# Fixtures are not included

This directory intentionally contains no extracted game data.

The server and tests expect externally supplied fixture/master-data files such
as gacha pools, quest catalogs and card progression tables. Those files may be
subject to third-party rights and are not redistributed here.

For local development, place lawfully obtained fixture files in this directory
using the filenames referenced by the source. Never commit account-specific
responses, cookies, tokens or save databases.
